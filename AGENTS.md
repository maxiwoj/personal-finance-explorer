# Agent instructions

- Avoid styling, formatting, or cosmetic UI changes that are not directly required to implement the current task.
- When a task requires a UI update, keep unrelated styles and component presentation unchanged.
- When you pick up a GitHub issue, first post a comment on that issue linking your session (e.g. `Implemented in Claude Code session: https://claude.ai/code/session_…`). A session that splits work into sub-issues or coordinates other sessions links itself on the parent issue.
